# 一个简单的表单验证

这是一个 前端页面表单提交验证，
暂时只写了姓名和电话两个，
配合HTML5自己的验证方法，
可以解决常见的表单验证

# 姓名&电话使用正则

姓名匹配中文字符，并且限制最长长度
电话匹配目前已有号段，并且限制长度为11位

# 更好兼容

IE7+,FF,OP,CHROME,亲测可用
